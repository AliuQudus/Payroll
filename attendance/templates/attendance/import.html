Import attendance

Load a CSV exported from a clock or spreadsheet. Columns: employee_no, date (YYYY-MM-DD or DD/MM/YYYY), status (present, late, absent or half_day), and optionally time_in, time_out (HH:MM) and note. Rows for a day that already has a record replace it. The import is all or nothing: if any row has a problem, none are saved and every problem is listed.
